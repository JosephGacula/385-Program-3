# Brief Write Up

The three saving mechanisms I tried to implement were a json, txt file, and then Unity prefs. I initially tried with json but found since I'm only doing 1 variable I could simplify the system. I then tried a txt file but
did not want to deal with file io. Unity prefs was the easiest solution here. For my main game I want to practice more with at least a json file as there will be more things to keep track of.
